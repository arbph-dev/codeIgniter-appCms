slugName (à généraliser) — core/text.py ou transformation/slug.py :

```py
import re
import unicodedata

def slug_name(value: str) -> str:
    if not value:
        return ""
    s = unicodedata.normalize("NFKD", value)
    s = "".join(c for c in s if not unicodedata.combining(c))
    s = s.lower().strip()
    s = re.sub(r"[^a-z0-9]+", "-", s)
    return s.strip("-")
```

Dates (_extract_date) — améliorer sans dynamisme excessif :
```py
from datetime import datetime

def extract_date(value) -> Optional[str]:
    """str | dict PHP | datetime → 'YYYY-MM-DD'."""
    if value is None:
        return None
    if isinstance(value, datetime):
        return value.date().isoformat()
    if isinstance(value, dict):
        value = value.get("date") or value.get("date_naissance")
    if not value:
        return None
    s = str(value).strip()[:10]
    # validation légère
    if len(s) == 10 and s[4] == "-" and s[7] == "-":
        return s
    return None
```
