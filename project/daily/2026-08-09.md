**Évolution proposée — `domhelper.pagination()`**

Un seul ajout : paramètre `onClick` en alternative à `busEvent`. Rétrocompatible — l'existant ne change pas.

javascript

```javascript
// domhelper.js — pagination()
// Signature actuelle
export function pagination({ pager, busEvent, style = 'compact', maxVisible = 7 })

// Signature proposée — onClick est prioritaire sur busEvent
export function pagination({ pager, busEvent, onClick, style = 'compact', maxVisible = 7 })
{
    // ... construction des boutons, puis :

    btn.addEventListener('click', () =>
    {
        if (onClick)        onClick(i)           // ← nouveau : callback direct
        else if (busEvent)  bus.publish(busEvent, i)  // ← existant : bus
    })
}
```

**Cascade ListPanel — `show()`**

javascript

```javascript
// Avant
if (pager) {
    this.pagerEl.appendChild(
        pagination({ pager, busEvent: 'wb:org:page', style: 'compact', maxVisible: 5 })
    )
}

// Après
if (pager) {
    this.pagerEl.appendChild(
        pagination({
            pager,
            onClick    : (page) => this._onPageFn?.(page),  // ← callback local
            style      : 'compact',
            maxVisible : 5,
        })
    )
}
```

`onPage(fn)` est déjà dans `OrgListPanel` — il suffit de le brancher. Même pattern pour tous les ListPanels.

**Cascade Workbench — `_bindEvents()` et `destroy()`**

javascript

```javascript
// Avant
_bindEvents() {
    // ...
    this._onPageFn = (page) => { this._page = page; this.load() }
    this.bus.subscribe('wb:org:page', this._onPageFn)          // ← bus
}

destroy() {
    this.bus.unsubscribe('wb:org:page', this._onPageFn)        // ← cleanup bus
    this._onPageFn = null
    // ...
}

// Après
_bindEvents() {
    // ...
    this.listPanel.onPage(page => { this._page = page; this.load() })  // ← callback
    // _onPageFn disparaît du Workbench
    // bus.subscribe disparaît du Workbench
}

destroy() {
    // Rien pour la pagination — ListPanel.destroy() nettoie _onPageFn = null
    // ...
}
```

---

**Ce qui disparaît de chaque Workbench**

diff

```diff
- this._onPageFn = null          // dans le constructor
- this._onPageFn = (page) => ... // dans _bindEvents
- this.bus.subscribe(...)         // dans _bindEvents
- this.bus.unsubscribe(...)       // dans destroy
- this._onPageFn = null           // dans destroy
```

5 lignes supprimées par Workbench. Le bus ne véhicule plus rien de local.

**Résultat final dans le contrat**

```
Panels → Workbench  : CALLBACKS (onSearch, onSelect, onNew, onSave, onDelete, onPage)
Workbench → Panels  : MÉTHODES  (show, clear, showLoading, showFeedback...)
Infrastructure IHM  : BUS       (dialog:*, leaflet:*)
```

La pagination rejoint les callbacks. Le bus ne transporte plus que l'infrastructure partagée — ce qui était l'objectif depuis le début.
