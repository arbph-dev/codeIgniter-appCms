## Point plus complexe

**attach_to_organisation** ( services/api/entreprise_client.py )

erreur :  
```
Push org#10: BaseApiClient.post() got an unexpected keyword argument 'json'
```

Adapter self.post(..., json=payload) au style exact de BaseApiClient.
- Si attach_to_organisation attend un dict plutôt que **kwargs : body,  data selon la signature

```Python
  result = ent_client.attach_to_organisation( rec.organisation_id, body,)
```

BaseApiClient non modifié
```Python
# services/api/BaseApiClient.py

    def post(self, endpoint: str = "", data: dict = None) -> Optional[dict]:
        return self._request("POST", endpoint, json=data)
```

attach_to_organisation à adapter json=payload devient donc data=payload 


```Python
# services/api/entreprise_client.py
    def attach_to_organisation(self, organisation_id: int, **payload) -> dict | None:
            """
            POST /organisation/{id}/entreprise
            Rattache une extension entreprise (+ siège si siret) à une org existante.
            """
            # json=payload devient donc data=payload 
            # data = self.post(f"/organisation/{organisation_id}/entreprise", json=payload)
            data = self.post(f"/organisation/{organisation_id}/entreprise", data=payload)
```
