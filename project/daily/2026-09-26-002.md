## 1. Approche méthodologique

### 1.1 Définition de la guideline

Inspirée par deux API de référence :
- **API Tâches** : project/Tasks (ID, DOMAINE/PROJET/TACHE)
- **API GMAO/Articles** : gestion des articles, fournisseurs, caractéristiques, prix

### 1.2 Couches d'implémentation

#### Backend
- **Routes** : contrat standard (LIST, SHOW, CREATE, UPDATE, DELETE, LIKE, BATCH)
- **SQL** :
  - Migrations MySQL + SQLite
  - Seeders (insert sans select)
- **Models** : retourType = Entity obligatoire
- **Entities** : definition des $casts
- **Controllers** : ApiResponse trait + ResourceController
- **Services** : logique métier
- **Tests** : curl + vues de test
- **Authentification** :
  - Register avec validation
  - User + Group permissions

#### Frontend
- **Controllers / Workbench** : coordination
- **Services / Store** : gestion d'état
- **Renderers, Forms / Panels** : composants UI

### 1.3 Intégration Orbis

**Orbis** (Python) utilisera la **couche 4 persistance** :
- Exports SQL/JSON
- Import MySQL en production après tests initiaux

## 2. Patterns d'API à respecter

### 2.1 Routes standard

```
GET    /api/{resource}                    # liste paginée
GET    /api/{resource}/like               # autocomplete  
GET    /api/{resource}/batch?ids=1,2,3    # multi-IDs
GET    /api/{resource}/:id                # détail
GET    /api/{resource}/:id/{relation}     # sous-ressource
POST   /api/{resource}                    # créer
PUT    /api/{resource}/:id                # modifier
DELETE /api/{resource}/:id                # supprimer
```

### 2.2 Query parameters

```
?fields=id,nom              # sparse fields (whitelist)
?sort=nom&order=asc         # tri contrôlé
?q=...                      # recherche
?len=10                     # limite autocomplete
?page=2&per_page=20         # pagination
?include=rel1,rel2          # include optionnel (detail)
```

### 2.3 Réponse standardisée

```json
{
    "status": 200,
    "data": [...],
    "meta": {
        "page": 1,
        "per_page": 20,
        "total": 150,
        "pages": 8,
        "q": "search_term",
        "sort": "nom",
        "order": "asc",
        "fields": ["id", "nom"],
        "has_more": true
    }
}
```

### 2.4 Traits et héritage obligatoires

```php
use App\Traits\ApiResponse;
use CodeIgniter\RESTful\ResourceController;
```
