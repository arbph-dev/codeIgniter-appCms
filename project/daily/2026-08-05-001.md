# Phase A — Migration des Panels existants vers PanelBase

## Changements requis

### MotListPanel.js

```diff
+ import PanelBase from '/assets/js/ui/workbench/core/PanelBase.js'

- export class MotListPanel
+ export class MotListPanel extends PanelBase
  {
      constructor()
      {
+         super()
          this._onSelectFn = null
          ...
      }
```

### MotDetailPanel.js

```diff
+ import PanelBase from '/assets/js/ui/workbench/core/PanelBase.js'

- export class MotDetailPanel
+ export class MotDetailPanel extends PanelBase
  {
      constructor(config = {})
      {
+         super()
          this.element     = null   // ← déjà déclaré par PanelBase, peut être retiré
          this.bodyEl      = null
          ...
      }
```

### MotWorkbench.js

```diff
- import WorkbenchBase from '/assets/js/ui/workbench/WorkbenchBase.js'
+ import WorkbenchBase from '/assets/js/ui/workbench/core/WorkbenchBase.js'
```

Aucun autre changement fonctionnel.

---

## Ce qui ne change pas

- Les signatures de show() restent libres (MotListPanel.show(items, pager) / MotDetailPanel.show(mot))
- lock() / unlock() / showFeedback() restent dans MotDetailPanel — extensions propres au panel
- bindEvents() dans MotWorkbench est inchangé
- Aucun comportement modifié

---

## Validation

MotWorkbench doit fonctionner exactement comme avant après ces trois diff.
C'est la condition pour passer à Phase B.
