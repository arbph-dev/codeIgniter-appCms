## services/api/entreprise_client.py
### attach
```py
    def attach_to_organisation(self, org_id: int, **kwargs) -> Optional[dict]:
        """
        POST /organisation/:id/entreprise
        Rattache une extension entreprise à une organisation existante.
        Ne crée PAS une nouvelle org.

        kwargs : siren, siret, adresse_id, codenaf_id, forme_juridique_id,
                 capital, effectif_min, effectif_max, …
        """
        data = self.post(f"/organisation/{org_id}/entreprise", kwargs)
        self._save(data, "attach", {"org_id": org_id, **kwargs})
        return (data or {}).get("data")
```

# APPARTE A DEPLACER 
polymorphisme / organisation_type_id : pour l’instant un set TYPES_REQUIRING_ENTREPRISE = {1}. 

Le même pattern servira pour produit_type_id → table enfant (composant, media…). 

Pas besoin de requêtes complexes : la règle « type X ⇒ enfant obligatoire » est déclarative dans Orbis.

Types qui doivent avoir une entreprise **Convention simple à centraliser plus tard **
```py
# types d'organisation qui exigent une extension entreprise
TYPES_REQUIRING_ENTREPRISE = {1}   # 1 = Entreprise (ton seeder)
```

Une org est orpheline structurelle si :
  organisation_type_id ∈ TYPES_REQUIRING_ENTREPRISE
  et aucune ligne entreprises avec ce organisation_id

(Ce n’est pas la même chose que « sans SIREN » — list_orphans actuel filtre le SIREN.)
