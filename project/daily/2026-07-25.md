## Développement

On va faire évoluer les composants et les workbench puis la partie MVC

Pour plus de flexibilité l'emploi de page html peut être considéré (voir selon authentification et navigation)
- un dossier /pgcmp pour les page composants 
- un dossier /pgwkb pour les page workbench

Le but est de fournir des applications mais aussi des API 
Il est essentiel de séparer les fonctions fourniture de structure HTML mis en forme par CSS de l'hydratation de cette structure
Ceci permettra également d'illustrer l'emploi des API 
Les applications plus complexes reposeront au maximum sur les apis mais pourront être hybrides pour les plus complexes selon leur stade d'avancement ou des choix réalisés

### Processus 
Les workbench font progresser par itération successive
on va modifier le js/core le css au besoin
implémenter le workbench
tester
modifier les fichiers core, workbench ,css voir les composants
valider le workbench

On modifiera ensuite le MVC, principalement la partie, vue et layout
Enfin on pourra aborder d'autres API qui nécessiteront d'autres composants et workbench
