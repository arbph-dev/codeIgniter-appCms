                ? '✅ has("apex")'

                ? '❌ has("unknown")'
                : '✅ has("unknown") = false';

            // ---- get()

            if ($definition !== null)
            {
                $log[] = '<h4>get("apex")</h4>';

# définitions de composants

Les définitions de composants sont stockés dans la table component_types et doit être harmonisé avec le coté client
    app/Libraries/Components/ComponentDefinition
Les fichiers JavaScript suivant doivent permettre de géré ces définitions     
    assets/js/core/ComponentDefinition.js

## [app/Models/ComponentTypeModel.php](/refactoring/app/Models/ComponentTypeModel.php)
```
class ComponentTypeModel extends Model
{
    protected $table      = 'component_types';
    protected $primaryKey = 'id';
    protected $returnType = 'array';

    protected $allowedFields = [
        'name',
        'view',
        'description',
        'is_active',
    ];

    /** Retourne tous les types actifs.    */
    public function findActive(): array

   /** Retourne un type à partir de son nom.  */
    public function findByName(string $name): ?array

    /** Retourne la correspondance id => name. */
    public function getTypeMap(): array
}
```
