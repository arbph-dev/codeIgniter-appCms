### base de données
- suppression de siret dans la table entreprises de la base de données
- modification du model

```sql
-- 1. (Optionnel) Sauvegarder les siret entreprise → établir sièges manquants
--    à faire en script de données si des lignes entreprises.siret sont renseignées
-- 2. Retirer siret de entreprises
ALTER TABLE entreprises DROP INDEX siret;   -- nom d'index UNI éventuel
ALTER TABLE entreprises DROP COLUMN siret;
-- 3. Index utile pour le siège (optionnel mais recommandé)
ALTER TABLE etablissements
  ADD INDEX idx_org_siege (organisation_id, is_siege);
```

### [app/Services/EntrepriseService.php](/refactoring/app/Services/EntrepriseService.php)
Règles métier :
- SIREN porté par organisations.siren
- SIRET uniquement sur etablissements (siège = is_siege = 1)
- 1 organisation ↔ 0..1 entreprise (organisation_id UNIQUE)
- createWithOrganisation : org + entreprise + siège (si siret)
- attachToOrganisation  : extension entreprise sur org existante



#### [createWithOrganisation](/refactoring/app/Services/EntrepriseService.php#L45)

Création complète (nouvelle org + entreprise + siège optionnel)

```php
public function createWithOrganisation(array $data): array
```

createWithOrganisation(payload)
- transaction :
  - INSERT organisation (nom, siren, type, …)
  - INSERT entreprise (organisation_id, naf, forme, capital, …)
  - SI siret fourni :
    - INSERT etablissement (organisation_id, siret, nic, is_siege=1, adresse_id?)
  - return entreprise + org + siège

```
@param array $data
  nom (requis) , siren , organisation_type_id , siret , adresse_id
- codenaf_id
- forme_juridique_id
- capital
- effectif_min
- effectif_max

@return array entreprise complète (withRelations + siège)
```

#### [ensureSiege](/refactoring/app/Services/EntrepriseService.php#L238)
Crée ou met à jour l'établissement siège social.
- Garantit un seul is_siege = 1 par organisation.
  met is_siege = 0 sur les autres établissements de l’org ;
- Vérifie cohérence SIRET / SIREN si siren connu.
  normalise le SIRET (14 chiffres) et extrait le NIC

upsert l’établissement siège mais refuse si adresse_id absent et mode strict. (optionnel)


ensureSiege(organisationId, siret, adresseId?, …)
  → crée ou met à jour l’établissement is_siege
  → désactive is_siege sur les autres de la même org

```php
public function ensureSiege(
        int     $organisationId,
        string  $siret,
        ?int    $adresseId = null,
        ?string $nom = null,
        ?string $siren = null
    ): array
```
