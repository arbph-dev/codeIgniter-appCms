## 4. PanelStyles — niveau PanelBase

Oui : **l’abstraction vit sur PanelBase**, pour List **et** Detail (et panels spéciaux).

### Forme proposée

JavaScript

```
// assets/js/ui/workbench/core/PanelStyles.js

/**
 * Jetons CSS structurels d’un Panel.
 * Surcharge partielle possible : { ...DEFAULT_LIST_STYLES, root: 'wb_image_list_panel' }
 */
export const DEFAULT_LIST_STYLES = Object.freeze({
    root        : 'wb_list_panel',
    header      : 'wb_panel_header',   // aussi utilisé par toolbar.template
    btn         : 'wb-btn',
    btnNew      : 'wb-btn',            // surcharger si accent (ex. wb_mot_new_btn)
    search      : 'wb_list_search',
    searchInput : 'wb_list_search_input',
    searchBtn   : 'wb-btn',
    body        : 'wb_list_body',
    pager       : 'wb_list_pager',
    table       : 'cp_table',
    // états sélection (lignes / cartes) — theming ultérieur
    selected    : 'selected',
})

export const DEFAULT_DETAIL_STYLES = Object.freeze({
    root   : 'wb_detail_panel',
    header : 'wb_panel_header',
    body   : 'wb_panel_body',
    btn    : 'wb-btn',
})

/** Merge shallow : override gagne. */
export function createPanelStyles(defaults, override = {}) {
    return Object.freeze({ ...defaults, ...override })
}
```

### Branchement PanelBase

JavaScript

```
// PanelBase.js (extrait)
export class PanelBase {
    /**
     * @param {object} [options]
     * @param {object} [options.styles]  PanelStyles partiel ou complet
     */
    constructor({ styles = null } = {}) {
        this.styles = styles
            ? createPanelStyles(this._defaultStyles(), styles)
            : createPanelStyles(this._defaultStyles())
    }

    /** Sous-classes : DEFAULT_LIST_STYLES | DEFAULT_DETAIL_STYLES | {} */
    _defaultStyles() {
        return {}
    }
}
```

JavaScript

```
// ListPanelBase
_defaultStyles() {
    return DEFAULT_LIST_STYLES
}

render() {
    this.element = create('section', { class: this.styles.root })
    // …
    this.tableEl = create('div', { class: this.styles.body })
    this.pagerEl = create('div', { class: this.styles.pager })
}

_renderSearch() {
    const wrap = create('div', { class: this.styles.search })
    this.inputEl = create('input', {
        type: 'search',
        class: this.styles.searchInput,
        placeholder: this._searchPlaceholder,
    })
    const btn = create('button', {
        type: 'button',
        class: this.styles.searchBtn,
        text: 'Rechercher',
    })
    // …
}
```

JavaScript

```
// ImageListPanel — override minimal
super({
    styles: {
        root : 'wb_image_list_panel',
        body : 'wb_image_grid',   // si on mappe body → gridEl
    },
})
// + classes carte en constantes locales (métier), hors PanelStyles structurel
```

## 5. Theming clair / sombre (suite)

PanelStyles = **noms de classes**, pas les couleurs.

Les couleurs restent dans les **CSS variables** déjà documentées (--wb-bg, --wb-panel, --wb-text, …) sur :root / #modelworkbench.

text

```
PanelStyles.root  →  .wb_list_panel { background: var(--wb-panel); color: var(--wb-text); }
data-theme="light" | "dark"  sur  html / #workbench  →  bascule des variables
```

Pas besoin de changer les classes JS pour un thème clair ; seulement le fichier CSS (ou un second set de variables).

Évolution possible plus tard :

JavaScript

```
styles: { root: 'wb_list_panel wb_list_panel--compact' }
// ou data-attribute posé par le Workbench
```

## 7. Recommandation d’implémentation

1. Figer le **canon** ListPanelBase (wb_list_* + wb_panel_header + wb-btn).
2. Introduire PanelStyles.js + branchement dans PanelBase / ListPanelBase.
3. Mot / Org / Adresse : **plus de wb_mot_* structurels** ; CSS Mot mis à jour ou alias.
4. Image / Tagger : override root / body (+ tokens carte en local).
5. Theming clair/sombre : uniquement variables CSS, pas un second PanelStyles.

En résumé : **PanelStyles au niveau PanelBase**, défaut liste = classes du squelette ListPanelBase, overrides par constructeur, Mot et suivants sur le canon sauf contrainte (grille Image).
