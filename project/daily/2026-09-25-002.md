On établit un **référentiel transversal** avec les relations :
- constructeur = article - organisations : `FOREIGN KEY (manid) REFERENCES organisations(id)`
- fournisseur = articlefournisseur - organisations `FOREIGN KEY (fourid) REFERENCES organisations(id)`


```
organisations
       ▲
       │ manid
       │
     article
       │
       ├── typid ─────────► articletype
       ├── artid ─────────► articlecaracteristique
       └── artid ─────────► articlefournisseur
                                  └── fourid ───► organisations
articlefournisseur
       │
       └── artfid ─────────► articleprix
```

### article



```sql

-- =====================================================================
-- GMAO - MODULE ARTICLES
-- Migration initiale MySQL
-- =====================================================================

SET NAMES utf8mb4;
SET FOREIGN_KEY_CHECKS = 0;

CREATE TABLE IF NOT EXISTS article
(
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,

    lbl VARCHAR(255) NOT NULL,
    `desc` TEXT NULL,

    -- Organisation fabricant
    manid BIGINT UNSIGNED NULL,

    mdl VARCHAR(255) NULL,
    ean VARCHAR(32) NULL,

    -- Type fonctionnel de l'article
    typid BIGINT UNSIGNED NULL,

    ref VARCHAR(255) NULL,

    stock DECIMAL(15,3) NOT NULL DEFAULT 0,
    stockmini DECIMAL(15,3) NOT NULL DEFAULT 0,
    stockmaxi DECIMAL(15,3) NULL,

    unite VARCHAR(20) NULL,
    emplacement VARCHAR(255) NULL,
    actif TINYINT(1) NOT NULL DEFAULT 1,

    -- Zone d'extension pour les données encore non normalisées
    data JSON NULL,

    created_at DATETIME NULL,
    updated_at DATETIME NULL,

    PRIMARY KEY (id),

    KEY idx_article_lbl (lbl),
    KEY idx_article_ref (ref),
    KEY idx_article_ean (ean),
    KEY idx_article_manid (manid),
    KEY idx_article_typid (typid),
    KEY idx_article_actif (actif),
    KEY idx_article_stock (stock),

    CONSTRAINT fk_article_manid
        FOREIGN KEY (manid)
        REFERENCES organisations(id)
        ON DELETE SET NULL
        ON UPDATE CASCADE,

    CONSTRAINT fk_article_typid
        FOREIGN KEY (typid)
        REFERENCES articletype(id)
        ON DELETE SET NULL
        ON UPDATE CASCADE
)
ENGINE = InnoDB
DEFAULT CHARSET = utf8mb4
COLLATE = utf8mb4_unicode_ci;
```


### articlefournisseur
Le fabricant ou fournisseur est une **organisation**, l'établissement représente une implantation précise.
> « Le relais est acheté chez Rexel Rennes et non simplement chez Rexel »

a prévoir etbid  → etablissements.id
```
    etbid BIGINT UNSIGNED NOT NULL,

    CONSTRAINT fk_articlefour_etablissement
        FOREIGN KEY (etbid)
        REFERENCES etablissements(id)
        ON DELETE CASCADE
        ON UPDATE CASCADE
```


```sql
CREATE TABLE IF NOT EXISTS articlefournisseur
(
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,

    artid BIGINT UNSIGNED NOT NULL,

    -- Organisation fournisseur
    fourid BIGINT UNSIGNED NOT NULL,

    ref_four VARCHAR(255) NULL,
    prix DECIMAL(15,2) NULL,
    devise VARCHAR(3) NOT NULL DEFAULT 'EUR',
    delai INT NULL,
    actif TINYINT(1) NOT NULL DEFAULT 1,

    PRIMARY KEY (id),

    KEY idx_articlefour_artid (artid),
    KEY idx_articlefour_fourid (fourid),
    KEY idx_articlefour_actif (actif),

    CONSTRAINT fk_articlefour_article
        FOREIGN KEY (artid)
        REFERENCES article(id)
        ON DELETE CASCADE
        ON UPDATE CASCADE,

    CONSTRAINT fk_articlefour_organisation
        FOREIGN KEY (fourid)
        REFERENCES organisations(id)
        ON DELETE CASCADE
        ON UPDATE CASCADE
)
ENGINE = InnoDB
DEFAULT CHARSET = utf8mb4
COLLATE = utf8mb4_unicode_ci;
```
