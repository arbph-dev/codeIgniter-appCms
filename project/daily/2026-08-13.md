#### App/Controllers/Api/Personne.php
```
$routes->group('api', ['namespace' => 'App\Controllers\Api'], static function ($routes) {
    $routes->resource('personnes', [ 'controller' => 'Personne', 'only' => ['index', 'show', 'create', 'update', 'delete'],]);
    // Fusion
    $routes->post('personnes/(:num)/merge/(:num)', 'Personne::merge/$1/$2');
});
```

#### Enregistrement du Service (optionnel mais propre)
Dans app/Config/Services.php :
```PHP
public static function personne(bool $getShared = true)
{
    if ($getShared) {
        return static::getSharedInstance('personne');
    }

    return new \App\Services\PersonneService();
}
```
Ensuite on peut l'appeler ainsi :
```PHP
$service = service('personne');
```
