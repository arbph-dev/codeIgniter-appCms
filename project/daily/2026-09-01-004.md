# services/api/image_client.py

Deux points importants

1. get_url() utilise https://zealot.fr, pas https://zealot.fr/api.

Le champ path de l'image correspond au chemin du fichier statique, par exemple /assets/img/uploads/...; il faut donc construire l'URL depuis la racine du site. Le contrôleur d'upload confirme le stockage sous /assets/img/uploads/.

2. include="mots" est déjà supporté.

Cela nous permet de tester l'hypothèse suivante avant de créer ImageMotClient :

image = client.get_by_id(123, include="mots")

Si la fiche Image fournit déjà suffisamment bien la relation mots, on pourra éventuellement éviter un client séparé pour certaines opérations. En revanche, les opérations d'association/dissociation/synchronisation restent des endpoints distincts ; c'est ce que nous vérifierons au deuxième temps.

Étape suivante : brancher ImageClient dans cli/menus/image.py, avec liste → recherche → fiche → ouverture navigateur, puis on regardera concrètement la structure mots avant de décider si ImageMotClient est justifié.
