## Renderer et descriptor

Le Descriptor est premier. Le composant n'existe que parce qu'il existe un Descriptor.
Autrement dit : Descriptor -> Component


Le renderer ne fait quasiment rien. Le renderer n'interprète rien. Il transporte, c'est est un pont.
```
$options = $descriptor->get('options', []);
```
puis
```
data-options="..."
```

voir : https://github.com/arbph-dev/codeIgniter-appCms/blob/main/documentation/ARCHITECTURE/ARCHITECTURE-OVERVIEW.md#descriptordefinition
