```py
def menu(titre: str, items: list[str]) -> str:
    """Affiche un menu numéroté et retourne le choix (str)."""
    console.print(f"\n[bold cyan]{titre}[/]")
    for i, label in enumerate(items, 1):
        console.print(f"  [cyan]{i}[/]  {label}")
    console.print(f"  [cyan]0[/]  Retour")
    return Prompt.ask(
        "Choix",
        choices=["0"] + [str(i) for i in range(1, len(items) + 1)],
    )
```

## Backend
### ban_id doit être ajouté
Le schéma actuel de adresses ne contient aucun identifiant BAN. ban_id est alphanumérique.

champ: ban_id VARCHAR(32) NULL
```sql
ALTER TABLE `adresses` ADD `ban_id` VARCHAR(32) NULL AFTER `precision`;
```

index : INDEX idx_ban_id (ban_id)
```sql
ALTER TABLE `adresses` ADD INDEX `idx_ban_id` (`ban_id`);
```
mais pas UNIQUE
DES adresse Zealot pourront correspondrent à un seul enregistrement BAN car une adresse Zealot est précise a la porte et l'étage près
