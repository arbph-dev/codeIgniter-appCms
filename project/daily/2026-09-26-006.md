# gérer des droits

## droits dépendants du contexte 
la gestion par groupes globaux de CodeIgniter Shield (RBAC) doit être combinée avec des vérifications de relations en base de données (ABAC / Ownership).
- « être le créateur de la tâche »
- « être le responsable du projet X »)

Shield gère très bien la question :
- « L'utilisateur a-t-il le droit d'éditer une tâche en général ? »

En revanche, des questions nécessitent de vérifier l'entité en base de données : 
- « L'utilisateur est-il le créateur de CETTE tâche précise ? » 

## Modèle de données nécessaire
Pour faire fonctionner cette logique, il faut lier les utilisateurs aux projets et conserver l'auteur de chaque tâche :

### projects
champs : id, name, created_at
- relation Organisation/entreprise/Etablissement
 
### project_members
champs : project_id, user_id, role (ex : 'manager', 'editor', 'reader')

### tasks
champs : id, project_id, created_by (ID de l'utilisateur), title, status

## permissions granulaires
plutôt que de tout verrouiller uniquement par groupe : utiliser un domaine ici **tasks**

```php
public array $permissions = [
    'tasks.view'   => 'Voir les tâches',
    'tasks.create' => 'Créer des tâches',
    'tasks.edit'   => 'Éditer ses propres tâches',
    'tasks.manage' => 'Gérer toutes les tâches d\'un projet',
];

public array $matrix = [
    'TaskAdmin' => [ 'tasks.*' ] ,
    'TaskEditor' => [ 'tasks.view', 'tasks.create', 'tasks.edit' ] ,
    'TaskReader' => [ 'tasks.view' ]
];
```

## Implémentation du contrôle d'accès contextuel

Pour valider les règles métier avant une action, créez une classe de service ou un helper d'autorisation (type Policy) :

```php
namespace App\Authorization;

use App\Models\ProjectMemberModel;
use App\Models\TaskModel;
use CodeIgniter\Shield\Entities\User;

class TaskPolicy
{
    /**
     * Vérifie si un utilisateur peut modifier ou valider une tâche.
     */
    public static function canEdit(User $user, object $task): bool
    {
        // 1. Les administrateurs généraux ont tous les droits
        if ($user->inGroup('TaskAdmin')) {
            return true;
        }

        // 2. Vérification si l'utilisateur est responsable (Manager) du projet associé
        $memberModel = new ProjectMemberModel();
        $isManager = $memberModel->where([
            'project_id' => $task->project_id,
            'user_id'    => $user->id,
            'role'       => 'manager',
        ])->first();

        if ($isManager) {
            return true;
        }

        // 3. Un TaskEditor peut modifier/valider uniquement la tâche qu'il a créée
        if ($user->hasPermission('tasks.edit') && (int) $task->created_by === (int) $user->id) {
            return true;
        }

        return false;
    }

    /**
     * Vérifie si un utilisateur peut supprimer une tâche.
     */
    public static function canDelete(User $user, object $task): bool
    {
        if ($user->inGroup('TaskAdmin')) {
            return true;
        }

        $memberModel = new ProjectMemberModel();
        return (bool) $memberModel->where([
            'project_id' => $task->project_id,
            'user_id'    => $user->id,
            'role'       => 'manager',
        ])->first();
    }
}

```

## Utilisation dans vos contrôleurs / API
Lors de la réception d'une requête d'API
(PUT /api/tasks/{id}) :
```php
use App\Authorization\TaskPolicy;
use App\Models\TaskModel;

class TaskController extends ResourceController
{
    public function update($id = null)
    {
        $user = auth()->user();
        $taskModel = new TaskModel();
        $task = $taskModel->find($id);

        if (! $task) {
            return $this->failNotFound('Tâche introuvable.');
        }

        // Vérification de la permission contextuelle
        if (! TaskPolicy::canEdit($user, $task)) {
            return $this->failForbidden('Vous n\'avez pas la permission de modifier cette tâche.');
        }

        // Traitement de la mise à jour / validation
        $data = $this->request->getRawInput();
        $taskModel->update($id, $data);

        return $this->respondUpdated(['message' => 'Tâche mise à jour avec succès.']);
    }
}

```
