## ProfileClient
Orbis devrait pouvoir avoir une notion locale de profil courant : ProfileClient (client orbis)

On aura
- AuthProvider qui sait obtenir une session authentifiée.
- UserProfile qui utilise cette session pour interroger l'identité courante.

```
CredentialsStore
       │
       ▼
AuthProvider
       │
       │ get_session()
       ▼
ProfileClient(auth)
       │
       │ GET /api/auth/me
       ▼
CodeIgniter AuthController::me()
       │
       ▼
Profile
```

```py
class ProfileClient(BaseApiClient):

    def __init__( self, auth, timeout: int = 10, save_samples: bool = False,):
        super().__init__( ZEALOT_BASE, auth=auth, timeout=timeout, save_samples=save_samples,)

    def me(self):
        return self.get("/api/auth/me")
```


ProfileClient ne doit absolument pas refaire le login.
ProfileClient ne doit pas devenir un client d'administration des utilisateurs.
On n'a pas besoin de construire un système User/Group/Permission côté Orbis. Le serveur possède déjà le concept.

Le menu pourrait ensuite avoir quelque chose de ce genre :
```py
auth = get_auth(store, service)

if auth:
    profile = ProfileClient(auth)
    me = profile.me()
```
