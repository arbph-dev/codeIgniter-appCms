Contrat définitif des Panels
Tous les Panels auront exactement la même API :
    constructor()
    render()     -> retourne le Node racine
    show(data)   -> affiche des données
    clear()      -> remet à l'état vide
    destroy()    -> optionnel

Seule exception CatalogPanel qui conservera en plus refresh() car il gère un filtrage/tri local.

Contrat du Workbench

Le ComponentCatalogWorkbench sera le seul à :
créer les panels ;
appeler render() ;
faire les appendChild() ;
propager les données via show() ;
gérer la sélection.

Les panels ne contiendront aucune logique métier.
