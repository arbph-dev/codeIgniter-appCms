# Nav dynamique

on doit créer autant de `div.nav-header-row`

initArticlesNavigation doit disparaitre


```js
      const article = button.closest(".nav-article");
      if (!article) return;

      const open = article.classList.toggle("open");

```
comment utiliser aria-expanded
```
<button class="nav-toggle" type="button" aria-label="Développer le menu Automates" aria-expanded="false">

```

```js
button.setAttribute("aria-expanded", open ? "true" : "false");
```
