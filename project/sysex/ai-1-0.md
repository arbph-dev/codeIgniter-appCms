## Fait.py
La classe Fait permet de définir des faits avec des valeurs connues et inconnues en utilisant les paramètres optionnels (metaDATA) : "connu", "unite" et "valeur" dans la méthode __init__.

- Si la valeur du paramètre "connu" est False, cela signifie que la valeur du fait est inconnue.
- Si elle est True, cela signifie que la valeur est connue et peut être stockée dans le paramètre "valeur". 
-  Le paramètre "unite" permet de spécifier l'unité de mesure du fait. Par exemple :
```py
fait1 = Fait("température", connu=True, unite="degrés Celsius", valeur=25)
fait2 = Fait("pression", connu=False, unite="pascals")
```
