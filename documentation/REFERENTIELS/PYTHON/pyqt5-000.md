### <font color="#8064a2">QCheckBox</font>
<font color="#8064a2">**********************************************************************************************************</font>
Description :  
Case à cocher, permet une sélection binaire (coché/non coché).  
  
Exemple :  
  
```python   
from PyQt5.QtWidgets import QApplication, QCheckBox, QWidget, QVBoxLayout  
  
app = QApplication([])  
window = QWidget()  
layout = QVBoxLayout()  
  
checkbox = QCheckBox("Accepter les conditions")  
checkbox.stateChanged.connect(lambda state: print("Coché" if state else "Décoché"))  
layout.addWidget(checkbox)  
  
window.setLayout(layout)  
window.show()  
app.exec_()  
```

### <font color="#8064a2">QComboBox</font>  
<font color="#8064a2">**********************************************************************************************************</font>
Description :


### <font color="#8064a2">QProgressBar</font>
<font color="#8064a2">**********************************************************************************************************</font>
Description :  Barre de progression pour indiquer l'avancement d'une tâche.  
 
Exemple :  
```python   
from PyQt5.QtWidgets import QApplication, QProgressBar, QWidget, QVBoxLayout  
from PyQt5.QtCore import QTimer  
  
app = QApplication([])  
window = QWidget()  
layout = QVBoxLayout()  
  
progress = QProgressBar()  
progress.setMinimum(0)  
progress.setMaximum(100)  
layout.addWidget(progress)  
  
def update_progress():  
    val = progress.value() + 1  
    if val > 100:  
        val = 0  
    progress.setValue(val)  
  
timer = QTimer()  
timer.timeout.connect(update_progress)  
timer.start(100)  
  
window.setLayout(layout)  
window.show()  
app.exec_()  
```


### <font color="#8064a2">QTableWidget</font>
<font color="#8064a2">**********************************************************************************************************</font>   
Description :  Tableau pour afficher des données tabulaires avec des cellules éditables.  

Exemple :  
```python   
from PyQt5.QtWidgets import QApplication, QTableWidget, QTableWidgetItem  
  
app = QApplication([])  
table = QTableWidget()  
table.setRowCount(2)  
table.setColumnCount(3)  
table.setHorizontalHeaderLabels(["Nom", "Âge", "Ville"])  
  
table.setItem(0, 0, QTableWidgetItem("Alice"))  
table.setItem(0, 1, QTableWidgetItem("30"))  
table.setItem(0, 2, QTableWidgetItem("Paris"))  
  
table.setItem(1, 0, QTableWidgetItem("Bob"))  
table.setItem(1, 1, QTableWidgetItem("25"))  
table.setItem(1, 2, QTableWidgetItem("Lyon"))  
  
table.show()  
app.exec_()
```
### <font color="#8064a2">QTabWidget  </font>
<font color="#8064a2">**********************************************************************************************************</font>
Description :  Widget à onglets pour organiser plusieurs pages dans une même fenêtre.  
  
Exemple :  
```python   
from PyQt5.QtWidgets import QApplication, QTabWidget, QWidget, QVBoxLayout, QLabel  
  
app = QApplication([])  
window = QTabWidget()  
  
tab1 = QWidget()  
tab1_layout = QVBoxLayout()  
tab1_layout.addWidget(QLabel("Contenu de l'onglet 1"))  
tab1.setLayout(tab1_layout)  
  
tab2 = QWidget()  
tab2_layout = QVBoxLayout()  
tab2_layout.addWidget(QLabel("Contenu de l'onglet 2"))  
tab2.setLayout(tab2_layout)  
  
window.addTab(tab1, "Onglet 1")  
window.addTab(tab2, "Onglet 2")  
  
window.show()  
app.exec_()  
```
